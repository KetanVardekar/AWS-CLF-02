# CLF-C02 Prep

A simple study site for the AWS Certified Cloud Practitioner (CLF-C02) exam. It has two pages:

- **Cheat Sheet:** a keyword → concept → answer table for 26 topics, with a filter box.
- **Practice Exams:** 23 exams (1,142 questions). Click an answer to check it straight away. Right answers turn green. Wrong answers turn red, the card shakes (the phone vibrates too) and the correct answer is shown.

## Run

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # static site in dist/ (deploy anywhere)
```

## Editing content

- **Cheat sheet rows:** `src/data/keywords.ts` (`keyword`, `thinkOf`, `meaning`); topics are in `src/data/topics.ts`.
- **Exam questions:** `src/data/exams.json`. It is generated by `npm run build:exams`, which downloads the latest exam files from the source repo and converts them.
